My first project at Samsung, on the R&D team for Samsung Medison's Cloud Solutions. The goal was to take the video stream generated by an ultrasound machine and publish it to the web in real time, so a scan could be viewed remotely as it happened.

### The ffmpeg problem

The existing pipeline depended on ffmpeg to read and display the generated stream. That dependency was a liability — it added latency, complicated licensing, and left us with limited control over buffering behaviour in a context where dropped frames matter clinically.

I built a replacement application that reads and displays the stream directly, implementing **double buffering** with **DirectShow** and **Media Foundation**. This removed the ffmpeg dependency entirely and gave us direct control over the frame pipeline.

### Stack

C++, C#, Python, JavaScript, WebRTC, libdatachannel, MediaMTX, named pipes, Docker, AWS, Azure
