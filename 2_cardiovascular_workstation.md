An end-to-end workstation for Samsung Medison's cardiovascular ultrasound line, spanning the Windows software that runs on the machine itself and the companion website clinicians use alongside it.

I worked across the full stack on this one, which is unusual for a medical device project and was the most instructive part of it — the constraints at the UI layer and the constraints at the database layer inform each other much more directly than they do in typical web work.

### What I did

- Implemented the server UI for both the Windows application and the website
- Engineered the backend design
- Architected the database management layer
- Deployed and configured the system in an on-premises hospital environment
- Mentored interns joining the team

### Stack

React, WPF, .NET, IIS Windows Server
